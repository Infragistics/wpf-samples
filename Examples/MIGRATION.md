Migration to modern .NET (summary)

- Target frameworks
  - Retargeted projects to modern .NET (net10.0-windows).
  - Adopted WindowsDesktop SDK with UseWPF enabled for WPF projects.

- Project files (SDK-style)
  - Converted legacy .csproj files to SDK-style (removed ToolsVersion, legacy GUIDs, explicit framework references).
  - Centralized shared settings via Directory.Build.props/Directory.Build.targets.

- NuGet/package management
  - Migrated from packages.config to PackageReference.
  - Simplified restore and enabled transitive dependencies.

- Solution/build configuration
  - Standardized on Debug|AnyCPU and Release|AnyCPU across all projects.
  - Removed x86-only mappings; disabled Prefer32Bit by default.
  - Fixed solution vs. project configuration mismatches (e.g., SamplesBrowser, Shared, Services).

- References and coupling
  - Replaced fragile binary reference to IGDashboardTile.exe with a ProjectReference to IGDashboardTile/IGDashboardTile.csproj.

- Cleanup of legacy artifacts
  - Removed .NET Framework-specific config (binding redirects, redundant System.* references provided by SDK).
  - Eliminated duplicate assembly metadata generated by SDK builds.

- Build outputs and infra
  - Unified output/intermediate paths through centralized props.
  - Removed/balanced brittle pre/post-build steps.

- Code adjustments
  - Minor fixes for API differences/obsoletions required by modern .NET.
